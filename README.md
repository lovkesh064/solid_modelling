# Solid Modelling Practice Repository

This repository serves as a collection of 3D CAD models, assembly designs, and parametric sketches created over a 2–3 month practice period in SOLIDWORKS.

## Key Highlights & Model Categories

* **Internal Combustion (IC) Engine Components & Assemblies:**
  * Piston, connecting rod, and cylinder block assemblies
  * Crankshaft and camshaft component designs
  * Various IC engine mechanisms and configurations

* **Couplings & Mechanical Joints:**
  * Oldham coupling design and assembly
  * Various flexible and rigid shaft couplings

* **Mechanical Linkages & Mechanisms:**
  * Multi-body part assemblies
  * Dynamic motion mechanisms and constraint layouts

* **CAD Drafts & Part Sketches:**
  * Fundamental 2D parametric sketches and feature practice files

---
*Note: Primary formats include `.SLDPRT` (Part files) and `.SLDASM` (Assembly files).*
